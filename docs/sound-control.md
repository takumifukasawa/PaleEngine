# PaleSoundMaker 仕様書

## 音再生コントローラー

### 基本機能
- 再生ボタンを押したら音を再生する
- 停止ボタンを押したら音を停止する
- シークバーを動かしたら音の再生位置を変更する

### 再生制御の詳細
- 再生中のシーク操作：音を一時停止してシーク後に再開
- 再生時間：144秒（120BPM x 72measure）
- リアルタイム時間表示：現在時間/総時間

## GLSLシェーダーエディター

### エディター機能
- **Ace.jsエディター**：プロフェッショナルなコードエディター
- **Vimモード**：Vimキーバインドでの操作
- **シンタックスハイライト**：GLSLコードの色分け表示（C++モード使用）
- **行番号表示**：自動的に行番号を表示
- **ダークテーマ**：`ace/theme/twilight`を使用

### シェーダー操作
- **コンパイル**：現在のシェーダーコードをコンパイルして音源を更新
- **リセット**：元のシェーダーコードに戻す
- **エラー表示**：コンパイルエラーを日本語で表示、エラー行をハイライト

## 保存・読み込み機能

### プロジェクト管理
- **名前付き保存**：プロジェクト名を付けて保存
- **プロジェクト読み込み**：保存済みプロジェクトの一覧から選択
- **自動保存**：テキストエリアの変更時に自動的にローカルストレージに保存
- **起動時復元**：アプリケーション起動時に最後の状態を復元

### ファイル操作
- **エクスポート**：現在のシェーダーコードを`.glsl`ファイルとしてダウンロード
- **インポート**：ローカルの`.glsl`または`.txt`ファイルを読み込み
- **ドラッグ&ドロップ**：ファイルをエディターにドロップして読み込み

## エラーハンドリング

### シェーダーエラー機能
- **詳細なエラー情報**：行番号とエラーメッセージを表示
- **エラーパーサー**：WebGLエラーメッセージを日本語に翻訳
- **アノテーション**：エラー行にマーカーを表示
- **エラー行スクロール**：エラー発生箇所へ自動スクロール

### 視覚的フィードバック
- **ボタン状態変更**：操作結果をボタンテキストで表示
- **確認ダイアログ**：データ消失を防ぐ確認ダイアログ
- **ドラッグ時の背景色変更**：ファイルドロップ時の視覚的フィードバック

## 技術仕様

### 使用技術
- **PaleGL**：カスタムWebGLレンダリングエンジン
- **GLSL Sound Synthesis**：頂点シェーダーでのリアルタイム音声生成
- **Ace.js**：コードエディターライブラリ
- **WebAudio API**：音声再生とバッファ管理
- **Transform Feedback**：シェーダーベースの音声処理

### ファイル構成
- `src/pages/main.ts`：メインアプリケーションロジック
- `src/pages/shaders/sound-vertex.glsl`：音声生成用GLSLシェーダー（1163行）
- `PaleGL/src/PaleGL/utilities/createGLSLSoundWrapper.ts`：音声ラッパー関数
- `PaleGL/src/PaleGL/utilities/shaderErrorParser.ts`：エラー解析ユーティリティ

## 操作方法

### 基本操作
1. **再生**：再生ボタンで音声開始/一時停止
2. **停止**：停止ボタンで音声停止、位置リセット
3. **シーク**：シークバーで再生位置変更
4. **編集**：エディターでシェーダーコードを編集
5. **コンパイル**：コンパイルボタンで変更を適用

### Vimモード操作
- `i`：インサートモード
- `Esc`：ノーマルモード
- `h/j/k/l`：カーソル移動
- `dd`：行削除
- `yy`：行コピー
- `p`：ペースト
- `/`：検索
- `:s/old/new/g`：置換

### 保存・読み込み
- **保存**：プロジェクト名を入力して保存
- **読み込み**：保存済みプロジェクト一覧から選択
- **エクスポート**：`.glsl`ファイルとしてダウンロード
- **インポート**：ローカルファイルを読み込み
