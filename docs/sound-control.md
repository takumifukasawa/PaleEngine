# PaleSoundMaker 仕様書

## 音再生コントローラー

### 基本機能
- **再生/一時停止ボタン**：音を再生/一時停止する
- **停止ボタン**：音を停止し、再生位置を0秒にリセットする
- **シークバー**：音の再生位置をリアルタイムで変更する

### 再生制御の詳細
- **再生中のシーク操作**：シーク開始時に自動的に音を一時停止し、シーク後に再生を再開
- **再生時間**：144秒（120BPM x 72measure）
- **リアルタイム時間表示**：「現在時間/総時間」形式で表示（例：「15.3s / 144.0s」）
- **自動停止**：音楽が最後まで再生されると自動的に停止状態に戻る

### UI仕様
- **再生ボタン**：緑色（#4CAF50）、再生中は「一時停止」表示
- **停止ボタン**：赤色（#f44336）
- **シークバー**：幅300px、緑色のスライダー
- **時間表示**：等幅フォント（monospace）でグレー色表示

## 技術仕様

### 使用技術
- **PaleGL**：カスタムWebGLレンダリングエンジン
- **GLSL Sound Synthesis**：頂点シェーダーでのリアルタイム音声生成
- **WebAudio API**：音声再生とバッファ管理
- **Transform Feedback**：シェーダーベースの音声処理
- **TypeScript**：型安全なJavaScript開発
- **Vite**：高速ビルドツール

### ファイル構成
- `src/pages/main.ts`：メインアプリケーションロジック（266行）
- `src/pages/index.html`：HTMLエントリーポイント
- `src/pages/shaders/sound-vertex.glsl`：音声生成用GLSLシェーダー
- `PaleGL/src/PaleGL/utilities/createGLSLSoundWrapper.ts`：音声ラッパー関数
- `PaleGL/src/PaleGL/utilities/shaderErrorParser.ts`：エラー解析ユーティリティ
- `PaleGL/src/PaleGL/core/glslSound.ts`：コア音声システム

### アプリケーション構造
- **UIコンポーネント**：プログラム的にDOM要素を作成
- **スタイリング**：JavaScript内でCSS文字列として定義
- **音声制御**：GLSLSoundWrapperを通じた音声操作
- **イベント処理**：マウス・タッチ対応のシーク機能

## 操作方法

### 基本操作
1. **再生/一時停止**：再生ボタンをクリックして音声の開始/一時停止を切り替え
2. **停止**：停止ボタンをクリックして音声停止、再生位置を0秒にリセット
3. **シーク**：シークバーをドラッグして任意の再生位置に移動

### シーク操作の詳細
- **ドラッグ開始**：再生中の場合、自動的に一時停止
- **ドラッグ中**：リアルタイムで時間表示が更新
- **ドラッグ終了**：元々再生中だった場合、新しい位置から再生を再開
